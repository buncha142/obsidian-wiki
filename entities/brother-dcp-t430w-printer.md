# Brother DCP-T430W Ink Tank Printer

## ข้อมูลทั่วไป
- **ประเภท:** เครื่องพิมพ์มัลติฟังก์ชันอิงค์เจ็ท ระบบแท็งก์ (Ink Tank) 3-in-1 — พิมพ์ / สแกน / ถ่ายเอกสาร
- **ยี่ห้อ/รุ่น:** Brother DCP-T430W
- **ปีที่ซื้อ:** สั่งซื้อ 2026-09-09 (การันตีวันจัดส่งภายใน 2026-09-15)
- **ราคา/ที่มา:** ซื้อจาก **IT City (Shopee Mall)** — ราคาเต็ม 5,590 บาท → ราคาขาย 4,649 บาท + ค่าจัดส่ง 91 บาท (ส่วนลดค่าจัดส่ง -91 บาท) ใช้โค้ด Shopee ลด -1,302 บาท **รวมยอดสั่งซื้อสุทธิ 3,347 บาท** (Standard Delivery ส่งธรรมดาในประเทศ)
- **จัดส่งไปที่:** ศูนย์ปฏิบัติธรรมพัทลุง ตำบลควนขนุน อำเภอเขาชัยสน จังหวัดพัทลุง 93130

## สเปกหลัก
- **ความเร็วพิมพ์:** Fast Mode 27 ppm (ขาวดำ) / 11 ppm (สี) — ISO Print Speed 16 ipm (ขาวดำ) / 9 ipm (สี)
- **ความเร็วถ่ายเอกสาร:** ISO Copy 11.0 ipm (ขาวดำ) / 3.5 ipm (สี) — ถ่ายสำเนาสูงสุด 99 แผ่นต่อครั้ง
- **ความละเอียด:** พิมพ์สูงสุด 1200 × 6000 dpi / สแกนกระจก 1200 × 2400 dpi
- **ADF:** ไม่มี — สแกนแบบ flatbed วางบนกระจกทีละแผ่น
- **Auto duplex:** ไม่มี — พิมพ์ 2 หน้าแบบ manual (พลิกกระดาษเอง)
- **หน่วยความจำ:** 128 MB
- **ถาดกระดาษ:** ถาดมาตรฐานด้านหน้าแบบกันฝุ่น 150 แผ่น (Standard Tray) + ช่องป้อนกระดาษด้วยมือทีละแผ่นด้านหลัง (Manual Feed Slot)
- **หน้าจอ:** ปุ่มไฟ LED แสดงสถานะเท่านั้น — **ไม่มีจอ LCD**
- **การเชื่อมต่อ:** Hi-Speed USB 2.0, Wi-Fi Direct, Wireless LAN **2.4 GHz / 5.0 GHz**
- **Mobile Print:** AirPrint, Mopria, Brother Mobile Connect App, Brother Print Service Plugin (Android)
- **OS ที่ผู้ผลิตระบุว่ารองรับ:** Windows 10 / 11, Windows Server 2016 / 2019 / 2022, **macOS v12 / v13 / v14**
- **หมึก:** ระบบแท็งก์เติม — ขาวดำ ~7,500 หน้า / สี ~5,000 หน้าต่อชุด
- **ขนาด / น้ำหนัก:** 390 × 343 × 148.5 มม. / 6.3 กก.
- **ประกัน:** ลงทะเบียนแล้ว — Inhouse (นำเครื่องเข้าศูนย์บริการ) ครอบคลุมทั้ง Part และ Labour เริ่ม 14/09/2026 **สิ้นสุด 13/12/2028** (รวม ~27 เดือน มากกว่าฐาน 2 ปีปกติ ~3 เดือน คาดว่าได้รับสิทธิ์โปรฯ ต่อประกันช่วงลงทะเบียน) หมายเลขเครื่อง (S/N): E83758H6H211561, ลงทะเบียนด้วยอีเมล buncha142@gmail.com

## การใช้งานจริง
- **ใช้ทำอะไรเป็นหลัก:** งานเอกสารธุรการ/คณะสงฆ์ — พิมพ์เอกสารราชการ สแกน และถ่ายสำเนา ^[inferred]
- **ใช้คู่กับอุปกรณ์/ซอฟต์แวร์อะไร:** [[entities/macmini-m4-2024|Mac mini M4]] และ [[entities/macbook-air-m2-2022|MacBook Air M2 (2022)]] ผ่าน AirPrint บน Wi-Fi, สแกนผ่าน Image Capture / Preview; สั่งพิมพ์จาก [[entities/iphone-13|iPhone 13]] และ [[entities/ipad-air-11-m2|iPad Air 11" M2]] ผ่าน AirPrint
- **ตั้งอยู่ที่ไหน:** โต๊ะทำงาน office "ห้องสติ"

## เหตุผลที่เลือกรุ่นนี้
เกณฑ์ที่ตั้งไว้: 3-in-1 A4, Wi-Fi + Wi-Fi Direct + USB, รองรับ AirPrint — ไม่ต้องการ ADF, auto duplex และ Ethernet

เทียบกับคู่แข่งในกลุ่มเดียวกันแล้ว DCP-T430W ชนะ 3 ข้อ:

| ประเด็น | DCP-T430W | คู่แข่ง |
|---|---|---|
| ราคา | ถูกที่สุดในกลุ่ม | Canon G3020 ~5,090 / Epson L3250 ~5,190 |
| หมึกดำต่อชุด | 7,500 หน้า | Epson หมึก 003 ได้ 4,500 หน้า (ต่างกัน 67%) |
| Wi-Fi | รองรับ **5 GHz** | Epson L3250/L3256 และ Canon G3020 เป็น 2.4 GHz อย่างเดียว |

## ปัญหา/ข้อจำกัดที่เจอ
- **Brother ระบุรองรับแค่ macOS v12–v14** แต่ [[entities/macmini-m4-2024|Mac mini M4]] รัน macOS Tahoe 26.6.2 — **ไม่ควรลง driver จากเว็บ Brother** ให้ใช้ AirPrint ซึ่งเป็นมาตรฐานในตัว macOS ครอบคลุมทั้งพิมพ์และสแกน (eSCL) ไม่ต้องพึ่ง driver ของผู้ผลิตและไม่ทิ้ง background process ไว้ในเครื่อง ^[inferred]
- **ลงทะเบียนประกันแล้ว (14/09/2026)** — ได้ระยะประกัน 14/09/2026–13/12/2028 (~27 เดือน) ยาวกว่าฐาน 2 ปีมาตรฐาน ~3 เดือน ยืนยันจากอีเมลตอบกลับของ Brother ประเทศไทย ไม่ใช่โปรฯ "ต่อประกัน 1 ปี" ที่เคยเจอเงื่อนไขหมดอายุก่อนหน้านี้
- ไม่มีจอ LCD — ตั้งค่า Wi-Fi ครั้งแรกต้องใช้ WPS ที่ router หรือแอป Brother Mobile Connect บนมือถือ
- **WPS ล้มเหลว (Error TS-07)** เมื่อลองจริง 2026-09-14 — เครื่องหาเราเตอร์ที่เปิด WPS ไม่เจอ เป็นไปได้ว่าเราเตอร์ไม่รองรับ/ปิด WPS ไว้ ให้ใช้วิธีแอป Brother Mobile Connect แทน (ป้อน SSID/รหัสผ่านตรงผ่าน wizard ไม่ต้องพึ่ง WPS)

## ข้อควรระวังตอนติดตั้ง
- **อย่าเสียบเครื่องพิมพ์เข้าช่อง battery backup ของ [[entities/zircon-pi-ups-1000va|ZIRCON Pi UPS]]** — เครื่องพิมพ์อิงค์เจ็ทดึงกระแสกระชากสูงตอนเปิดเครื่องและตอนล้างหัวพิมพ์ ให้ใช้ช่อง surge protection only (UPS ตัวนี้มีช่อง Printer/อุปกรณ์อื่นแยกไว้ 2 ช่อง) ^[inferred]

- [x] ขั้นที่ 1: ประกอบเครื่อง — เสียบปลั๊กช่อง surge protection
- [x] ขั้นที่ 2 ข้อ 1-2: เติมหมึกครบทุกสี + กดค้างปุ่ม Colour Copy 3 วินาที เพื่อ priming/ล้างหัวพิมพ์ — **เสร็จแล้ว**
- [x] ขั้นที่ 2 ข้อ 3: พิมพ์ Print Quality Check Sheet ตรวจแนวหัวพิมพ์ — ลายเส้นทั้ง 4 สี (M/C/Y/BK) ครบไม่ขาดช่วง **ผ่าน ไม่ต้องรัน cleaning ซ้ำ** (S/N: E83758H6H211561)
- [x] ขั้นที่ 3: ตั้งค่า Wi-Fi — WPS ล้มเหลว (Error TS-07) แต่สำเร็จผ่านแอป **Brother Mobile Connect** เครื่องพิมพ์เข้าร่วม Wi-Fi แล้ว
- [x] ขั้นที่ 4: เพิ่มเครื่องพิมพ์บน Mac — **เสร็จทั้ง Mac mini M4 และ MacBook Air M2** ผ่าน AirPrint บน Wi-Fi
- [x] ขั้นที่ 5: ทดสอบสแกนผ่าน Image Capture/Preview
- [x] ขั้นที่ 6: เปลี่ยนรหัสผ่านแอดมินเริ่มต้น

**การติดตั้งเสร็จสมบูรณ์ทุกขั้นตอน — เครื่องพร้อมใช้งานเต็มระบบ**

### ขั้นที่ 1: ประกอบเครื่อง (Unboxing & Physical Setup)
1. แกะเทปกาว/วัสดุกันกระแทกออกให้หมด (ด้านในและรอบตลับหมึก/หัวพิมพ์) — เช็คคู่มือ Quick Setup Guide ที่แถมมาประกอบ เพราะมีจุดที่ต้องดึงพลาสติกกันกระแทกออกทั้งด้านในฝาและถาดหมึก
2. ใส่กระดาษ A4 เปล่าลงถาดกระดาษด้านหน้า (Standard Tray)
3. **เสียบปลั๊กไฟที่ช่อง surge protection เท่านั้น** — **ห้ามเสียบเข้าช่อง battery backup ของ [[entities/zircon-pi-ups-1000va|ZIRCON Pi UPS]]** เพราะเครื่องพิมพ์อิงค์เจ็ทดึงกระแสกระชากสูงตอนเปิดเครื่องและตอนล้างหัวพิมพ์

### ขั้นที่ 2: เติมหมึกและ Priming ระบบ (ทำครั้งเดียวตอนแกะกล่อง)
1. เปิดฝาครอบตลับหมึก แกะจุกขวดหมึกที่แถมมา แล้วเทลงแท็งก์แต่ละสีจนถึงขีดบน (แท็งก์จะดูดหมึกเองอัตโนมัติ ไม่ต้องบีบ)
2. เปิดเครื่อง แล้ว **กดค้างปุ่ม Colour Copy 3 วินาที** เพื่อเริ่มรอบล้าง/ไล่อากาศระบบหมึกครั้งแรก (ใช้เวลาสักครู่ ห้ามปิดเครื่องระหว่างนี้)
3. รอจน LED สถานะนิ่ง แล้วพิมพ์ **Print Quality Check Sheet** เพื่อตรวจแนวหัวพิมพ์ (ปุ่มลัดตามคู่มือ Quick Setup Guide) — ถ้าลายเส้นขาดหรือเยื้อง ให้รันรอบ cleaning เพิ่มตามคู่มือ

**ขวดหมึกเติมทิ้งเลยไหม:** ขวดหมึกของ Brother รุ่นแท็งก์เติม ปริมาณต่อขวดออกแบบมาให้พอดีกับความจุแท็งก์ 1 ครั้งพอดี เทหมดแล้วมักไม่มีหมึกเหลือ ^[inferred] — ถ้าเทแล้วยังมีหมึกเหลือในขวด ให้ปิดจุกให้แน่นเก็บไว้ใช้เติมรอบถัดไปได้ ไม่ต้องทิ้งทันที ^[inferred] ส่วนขวดเปล่าแล้ว ให้แยกทิ้งตามหลักขยะสารเคมี/รีไซเคิลของพื้นที่ ไม่ทิ้งรวมขยะทั่วไปถ้ามีจุดรับแยก และห้ามนำขวดเปล่าไปเติมหมึกยี่ห้ออื่นแล้วใช้ซ้ำกับเครื่องนี้ ^[inferred]

### ขั้นที่ 3: ตั้งค่า Wi-Fi (เครื่องไม่มีจอ LCD ต้องใช้ 1 ใน 2 วิธีนี้)
- **วิธี WPS (เร็วสุด ถ้า router รองรับ):** กดปุ่ม **Wi-Fi ที่เครื่องพิมพ์ 3 ครั้ง** แล้วกดปุ่ม WPS ที่ router ภายใน ~2 นาที
- **วิธีแอป Brother Mobile Connect:** ลงแอปบน [[entities/iphone-13|iPhone 13]] หรือ [[entities/ipad-air-11-m2|iPad Air 11" M2]] แล้วทำตาม wizard เพื่อจับคู่เครื่องพิมพ์เข้า Wi-Fi 2.4/5GHz ที่บ้าน/ศูนย์ปฏิบัติธรรม

### ขั้นที่ 4: เพิ่มเครื่องพิมพ์บน Mac (ทำเหมือนกันทั้ง 2 เครื่อง — ไม่ต้องลง driver จากเว็บ Brother)
ทำตามขั้นตอนนี้แยกกันบน **ทั้ง [[entities/macmini-m4-2024|Mac mini M4]] และ [[entities/macbook-air-m2-2022|MacBook Air M2 (2022)]]** เพราะ macOS จับคู่เครื่องพิมพ์แยกตามเครื่อง Mac แต่ละเครื่อง:
1. ต่อ Mac เข้า Wi-Fi วงเดียวกับเครื่องพิมพ์
2. System Settings › Printers & Scanners › Add Printer, Scanner, or Fax — รอให้เครื่องพิมพ์ขึ้นในลิสต์ (ชื่อจะมีคำว่า **Brother DCP-T430W**)
3. เลือกเครื่อง แล้วดูช่อง "Use" — ต้องขึ้นเป็น **AirPrint** โดยอัตโนมัติ (ถ้าขึ้นเป็นชื่ออื่น ให้เลือก AirPrint เองจาก dropdown) — **ไม่ต้องดาวน์โหลด driver จากเว็บ Brother** เพราะผู้ผลิตระบุรองรับแค่ macOS v12–v14 แต่ทั้งสองเครื่องรัน macOS Tahoe แล้ว ^[inferred]
4. กด Add — เครื่องพิมพ์จะขึ้นในแท็บ Default ของทั้งสองเครื่อง
5. ทดสอบพิมพ์หน้าใดก็ได้จากแต่ละเครื่องเพื่อยืนยัน

### ขั้นที่ 5: ทดสอบสแกน
เปิด **Image Capture** หรือ **Preview › File › Import from Scanner** บนเครื่องไหนก็ได้ที่เพิ่มเครื่องพิมพ์แล้ว — ใช้งานได้ทันทีผ่าน eSCL ไม่ต้องลงซอฟต์แวร์เพิ่ม (สแกนได้ทีละแผ่นจากกระจก flatbed เท่านั้น ไม่มี ADF)

### ขั้นที่ 6: ความปลอดภัย (แนะนำทำหลังติดตั้งเสร็จ)
- เปลี่ยนรหัสผ่านแอดมินเริ่มต้น (พิมพ์ไว้ด้านหลังเครื่อง ช่อง "Pwd") ผ่านแอป Brother Mobile Connect หรือ Web Based Management (พิมพ์ IP เครื่องพิมพ์ในเบราว์เซอร์)
