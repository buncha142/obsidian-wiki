# Ajazz AKP03

## ข้อมูลทั่วไป
- **ประเภท:** อุปกรณ์เสริมเดสก์ท็อป / Stream control deck (6 Key + 3 Button + 3 Knob Multi-Control)
- **ยี่ห้อ/รุ่น:** Ajazz AKP03 Desktop Helper, ตัวเลือกสี Black
- **ปีที่ซื้อ:** สั่งซื้อผ่าน Shopee, ร้าน NAVA IT MALL (Mall) สั่งซื้อ 02-03-2026
- **ราคา/ที่มา (ถ้าจำได้):** ราคาสินค้า ฿1,690 (ลดจาก ฿3,599), ค่าจัดส่ง ฿38 (มีส่วนลดค่าจัดส่ง -฿38), หักโค้ด Shopee -฿423 → ยอดชำระจริง ฿1,267, ชำระผ่าน ShopeePay (ตัดบัญชีธนาคาร)

## สเปกหลัก
- **ชิป/CPU:** -
- **RAM:** -
- **Storage:** -
- **OS / Firmware version:** รองรับ Windows 7 ขึ้นไป และ macOS 10.13 ขึ้นไป ^[inferred]
- **อื่นๆ:**
  - ปุ่มกดแบบ LCD/Visual 6 ปุ่ม (ตั้งไอคอนเองได้), ปุ่มหมุนโลหะ (Knob) 3 ปุ่ม, ปุ่มสวิตช์เสริม 3 ปุ่ม ^[inferred]
  - มีหน้าจอ LCD ด้านข้างแสดงสถานะ CPU/Memory ของเครื่องแบบเรียลไทม์ ^[inferred]
  - เชื่อมต่อผ่านพอร์ต USB-C ^[inferred]
  - ขาตั้งปรับมุมได้ 40° แบบถอดได้ (Detachable Anti-Slip Stand) ^[inferred]
  - ขนาดตัวเครื่อง ~130×80×60mm, น้ำหนัก ~160g ^[inferred]
  - รับประกัน 1 ปี ศูนย์ไทย

## การใช้งานจริง
- **ใช้ทำอะไรเป็นหลัก:** อุปกรณ์ควบคุมเสริมสำหรับ stream/มัลติทาสก์บนเดสก์ท็อป
- **ใช้คู่กับอุปกรณ์/ซอฟต์แวร์อะไร:** ต่อใช้งานคู่กับ [[entities/macmini-m4-2024|Mac mini M4 (2024)]]
- **ตั้งอยู่ที่ไหน:** โต๊ะทำงาน office "ห้องสติ" (ตำแหน่งเดียวกับ Mac mini M4)
