# Baseus Rotation Countdown Timer Pro

## ข้อมูลทั่วไป
- **ประเภท:** เครื่องตั้งเวลา/นาฬิกาจับเวลาถอยหลัง (Digital Countdown Timer)
- **ยี่ห้อ/รุ่น:** Baseus เครื่องตั้งเวลา Pro (Rotation Countdown Timer Pro), ตัวเลือกสินค้าสีเทาเข้ม
- **ปีที่ซื้อ:** สั่งซื้อ 10-10-2024 ผ่าน Shopee, ร้าน base.us_digital.store (Mall), ได้รับสินค้า 12-10-2024
- **ราคา/ที่มา (ถ้าจำได้):** ราคาสินค้า ฿800 ลดเป็น ฿450 (x1), ค่าจัดส่ง ฿38, หักโค้ด Shopee -฿135 → ยอดชำระจริง ฿353, ชำระผ่าน ShopeePay (ตัดบัญชีธนาคาร)

## สเปกหลัก
- **ชิป/CPU:** -
- **RAM:** -
- **Storage:** -
- **OS / Firmware version:** -
- **อื่นๆ:**
  - จอแสดงผล LED ขนาด 3.2 นิ้ว ตัวเลขสีขาวขนาดใหญ่ ^[inferred]
  - ตั้งเวลาได้ในช่วง 0–99 นาที, 0–55 วินาที, รองรับทั้งนับขึ้นและนับถอยหลัง ^[inferred]
  - ปรับระดับเสียงได้ 3 ระดับ: ปิดเสียง / เสียงเบา 60–70dB / เสียงดัง 80–90dB ^[inferred]
  - ใช้ไฟจากถ่าน AAA 3 ก้อน (4.5V) ใช้งานได้นานสูงสุด ~3 เดือนแบบ standby ^[inferred]
  - ฐานแม่เหล็กติดกับพื้นผิวโลหะได้ (เช่น ตู้เย็น) ^[inferred]
  - ขนาดตัวเครื่อง 78×78×27.5mm, น้ำหนัก ~76g, วัสดุ ABS ^[inferred]
  - จดจำค่าตัวเลขที่ตั้งล่าสุดเพื่อรีเซ็ตใช้งานซ้ำได้รวดเร็ว ^[inferred]
