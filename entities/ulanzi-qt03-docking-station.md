# Ulanzi QT03 Docking Station

## ข้อมูลทั่วไป
- **ประเภท:** Docking Station / USB-C Hub (ตัวแปลงช่องเสียบพร้อมช่องใส่ SSD ในตัว)
- **ยี่ห้อ/รุ่น:** Ulanzi QT03, ตัวเลือกสินค้า SET QT01 + QT03
- **ปีที่ซื้อ:** สั่งซื้อผ่าน Shopee สั่งซื้อ 02-12-2025
- **ราคา/ที่มา (ถ้าจำได้):** ราคาสินค้า ฿9,009 (ลดจาก ฿15,999), ค่าจัดส่ง ฿38 (มีส่วนลดค่าจัดส่ง -฿38), หักโค้ด Shopee -฿2,000, โค้ดส่วนลดร้านค้า -฿9 → ยอดชำระจริง ฿7,000, ชำระผ่าน ShopeePay (ตัดบัญชีธนาคาร)

## สเปกหลัก
- **ชิป/CPU:** ใช้ชิป ASM2464PD และ VL822-07T สำหรับควบคุมการรับส่งข้อมูลความเร็วสูงและระบบป้องกัน (short-circuit, over-current) ^[inferred]
- **RAM:** -
- **Storage:** รองรับ M.2 NVMe SSD สูงสุด 8TB, ความเร็วจริงระดับ 3,000+ MB/s แบบถาด tool-free พร้อมแผ่นระบายความร้อนอะลูมิเนียม ^[inferred]
- **OS / Firmware version:** รองรับ macOS, Windows, Linux, Android, HarmonyOS โดยไม่ต้องลงไดรเวอร์เพิ่ม (บน macOS) ^[inferred]
- **อื่นๆ:**
  - มาตรฐาน USB4 ความเร็วสูงสุด 40Gbps (ไฟล์ 3GB โอนเสร็จใน ~1 วินาที) ^[inferred]
  - 10 พอร์ตในตัว: USB-A x2, USB-C x2, ช่องอ่านการ์ด SD/TF 4.0 (312MB/s รองรับสูงสุด 2TB), HDMI 4K@60Hz, ช่องเสียง 3.5mm, PD 3.0 fast charging (รับไฟ 100W / จ่ายไฟ 85W) ^[inferred]
  - มีพัดลมระบายความร้อนปรับได้ พร้อมแผ่นฐานอะลูมิเนียมและช่องระบายอากาศแบบตาข่าย ^[inferred]
  - ออกแบบให้ใช้งานร่วมกับ Mac mini M4/M4 Pro โดยเฉพาะ พร้อมขาตั้งในตัว ^[inferred]

## การใช้งานจริง
- **ใช้ทำอะไรเป็นหลัก:** ขยายพอร์ตเชื่อมต่อและเพิ่มที่เก็บข้อมูล (SSD) ให้เดสก์ท็อป
- **ใช้คู่กับอุปกรณ์/ซอฟต์แวร์อะไร:** ต่อใช้งานคู่กับ [[entities/macmini-m4-2024|Mac mini M4 (2024)]]
- **ตั้งอยู่ที่ไหน:** โต๊ะทำงาน office "ห้องสติ" (ตำแหน่งเดียวกับ Mac mini M4)
