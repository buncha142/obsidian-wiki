# Andrej Karpathy

นักวิจัย AI และ educator ที่มีอิทธิพลสูงในวงการ deep learning

## บทบาทสำคัญ

- **OpenAI** — cofounder, ทำงานช่วงแรก
- **Tesla** — Senior Director of AI (Autopilot team)
- **YouTube / X** — educator ชื่อดัง ทำ tutorials เกี่ยวกับ neural networks

## ผลงานที่เกี่ยวกับ vault นี้

เขียน [gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) อธิบาย pattern การใช้ LLM ดูแล personal knowledge base — ซึ่งเป็นต้นแบบของ [[llm-wiki-pattern]] และ vault นี้ทั้งหมด

แนวคิดหลักจาก gist:
> "แทนที่จะถาม LLM คำถามเดิมซ้ำ ๆ ให้ compile ความรู้ครั้งเดียวแล้วให้ LLM maintain"
