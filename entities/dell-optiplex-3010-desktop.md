## สภาพ
- ฝาข้างมีรอยขีดข่วนมาก ฝุ่นจับพัดลมซีพียูและภายในพอสมควร — ควรเป่าฝุ่นก่อนใช้งานต่อ
- หน้า IHS ของ CPU มีคราบซิลิโคนเก่า → เช็ดออกแล้วทาซิลิโคนใหม่ก่อนประกอบฮีตซิงก์กลับ ^[inferred]
- ส่วนอื่นดูครบ สายไฟเรียบร้อย

## ประวัติซ่อม/สถานะ
- **2026-10-16:** เปลี่ยน PSU ใหม่ → เปิดเครื่องได้ บูตถึงหน้า login ของ Windows 7 Ultimate ปกติ (ฮาร์ดแวร์ใช้งานได้)
- ติดรหัสผ่านบัญชี Windows **"NBE"** (ไม่ทราบรหัส) — ผู้ใช้ต้องการเก็บไฟล์ในบัญชีนี้ไว้ → แนวทาง: **ไม่รีเซ็ตรหัส** (เสี่ยงทำให้ไฟล์ที่เข้ารหัส EFS และรหัสที่เซฟไว้ในเบราว์เซอร์เปิดไม่ได้) แต่อ่านไฟล์จากดิสก์โดยตรง:
  - ถอด HDD ไปต่อกล่องหรือ dock สำหรับ HDD **3.5" ที่มีไฟเลี้ยง 12V** แล้วต่อเข้า Mac เพื่อ copy `Users\NBE\` ออกมา หรือ
  - บูต Linux Mint live USB บนเครื่องนี้ (กด F12 ตอนเปิดเครื่อง) แล้ว copy ไฟล์ลง USB

- **2026-10-16 ลง Linux Mint 22.3 ไม่สำเร็จรอบแรก:** ตัวติดตั้งผ่านขั้น "Erase disk" ไปแล้ว (Windows 7 + ไฟล์ NBE ในดิสก์ถูกลบ) แต่ติดตั้งไม่จบ รอบถัดมาเจอ `ubi-partman crashed exit code 10` เพราะ `/target` จากรอบก่อนยังเปิดค้างอยู่ ในดิสก์จึงมีแค่ `boot`, `etc`, `swapfile`
  - โครงสร้าง HDD ตอนนี้ (GPT): sda1 BIOS boot 1 MB · sda2 EFI FAT32 513 MB · sda3 ext4 465.3 GB
- **2026-10-16 ทดสอบ HDD บน [[entities/pc-ptmc072-desktop|PC-PTMC072]]:** Windows เห็นดิสก์ปกติ (Disk 1, GPT, Healthy) แต่ไม่ขึ้นใน File Explorer เพราะ Windows อ่าน ext4 ไม่ได้ · PredictFailure = False, Read errors 0, 30 °C, Power-On 13,782 ชม., Start/Stop 6,003 ครั้ง → **ฮาร์ดดิสก์ยังดี**
  - SMART เต็ม: 5 Reallocated **0** · 197 Pending **0** · 198 Offline Uncorrectable **0** · 187 Reported Uncorrectable 0 · 188 Command Timeout 0 · 183 Runtime Bad Block 0 · 184 End-to-End 0 · 189 High Fly Writes 0 · 199 UDMA CRC 0 · Power Cycles 5,972 · อุณหภูมิสูงสุดที่เคยบันทึก 42 °C (ค่า 1/7 Read/Seek Error Rate ของ Seagate เป็นตัวเลขรวมที่ดูดิบๆ ไม่ได้ ค่า normalized ยังสูงกว่าเกณฑ์)

- **2026-10-17 ลง Linux Mint 22.3 Cinnamon สำเร็จ** บน HDD Seagate 500 GB — รอบก่อนหน้าล้มเหลวด้วย `[Errno 5] Input/output error` ตอนก๊อปไฟล์ ~80% น่าจะมาจากแฟลชไดรฟ์ "ONE" (รุ่น `ProductCode` ไม่มียี่ห้อ) ^[inferred] รอบที่สำเร็จใช้การ์ด SD 16 GB ("NO NAME") ผ่านตัวอ่านการ์ด USB เป็นตัวติดตั้ง
  - โปรแกรมที่จะลง: VS Code (.deb Microsoft), Google Chrome (.deb Google), Claude Desktop (apt repo ทางการของ Anthropic — Linux beta รองรับ Ubuntu 22.04+/Debian 12+ จึงใช้กับ Mint 22 ได้)

## ข้อสังเกตการใช้งาน
- **Windows 7 หมดการสนับสนุนแล้ว** และ Windows 10 หมด ESU ผู้ใช้ทั่วไปแล้ว (13 ต.ค. 2026)
- **2026-10-16 ผู้ใช้เลือกลอง Linux Mint บน HDD 500 GB เดิม** (แนะนำ edition Xfce ระหว่างที่ RAM ยังเป็น 4 GB) — ต้อง copy ไฟล์บัญชี NBE ออกก่อน เพราะตัวติดตั้งแบบ "Erase disk" จะลบทั้งดิสก์; ถ้าย้ายไป SSD ภายหลังต้องลงใหม่หรือ clone ด้วย Clonezilla
- **OS ที่แนะนำเดิม (2026-10-16): Windows 11 Pro** ลงบน SSD ใหม่ผ่าน Rufus (ข้ามการตรวจ TPM/Secure Boot/RAM + ใช้บัญชี local)
  - i3-3220 ไม่ผ่านเกณฑ์ CPU ทางการ แต่มีคำสั่ง SSE4.2/POPCNT ครบ จึงลง Windows 11 24H2 ขึ้นไปได้ ^[inferred]
  - ถ้าใช้ RustDesk/AnyDesk แทน RDP ใช้ Windows 11 Home ก็พอ
  - key Windows 7 เดิมน่าจะใช้ activate ไม่ได้แล้ว → เผื่อซื้อ key ใหม่
  - ทางเลือก: Windows 10 IoT Enterprise LTSC 2021 (ได้อัปเดตถึงปี 2032) แต่ซื้อได้เฉพาะไลเซนส์องค์กร/OEM
  - ⚠️ อย่าสับสนกับ **Windows 10 Enterprise LTSC 2021 (ไม่มีคำว่า IoT)** ซึ่งหมดซัพพอร์ต **12 ม.ค. 2027** — ไม่คุ้มที่จะซื้อ (ตรวจสอบเมื่อ 2026-10-16 จากโฆษณาขาย key ลด 93% ซึ่งน่าจะเป็น key ตลาดเทา)
- การ์ด Parallel port ไม่จำเป็นสำหรับงานเสียงตามสาย — ถอดออกได้ ถ้าไม่มีเครื่องพิมพ์ LPT ที่ต้องใช้ ^[inferred]
- PSU 250 W ไม่มีหัว PCIe 6-pin → ใส่การ์ดจอได้เฉพาะรุ่นกินไฟจากสล็อต (≤75 W)
- **การ์ดจอ (ประเมิน 2026-10-16): ไม่จำเป็น** สำหรับงานเสียงตามสาย เพราะกราฟิกในตัว Intel HD 2500 พอแล้ว
  - GT210 1GB (Asus) และ GT610 2GB (Afox) ใส่ได้ทั้งคู่ (กินไฟราว 30 W ไม่ต้องต่อไฟเพิ่ม) แต่ต้องใช้**ขายึดแบบ low-profile** เพราะตัวถังเป็นแบบ DT
  - ไดรเวอร์ทั้งสองรุ่นหยุดพัฒนาแล้ว (GT210 สุดที่ Windows 10 ปี 2016, GT610 สุดที่ปี 2018) ไม่มีไดรเวอร์ Windows 11 อย่างเป็นทางการ ^[inferred]
  - เครื่องมี HDMI ในตัวแล้ว จึง**ตัดการ์ดจอออกจากแผน** (ถ้าวันหน้าต้องใส่จริง เลือก GT610 เพราะไดรเวอร์ใหม่กว่า)
- เหมาะเป็นเครื่องงานเอกสาร/เครื่องสำรอง ไม่เหมาะงานไลฟ์สด (เทียบ [[entities/pc-ptmc072-desktop|PC-PTMC072]])

## ที่ตั้ง/การใช้งาน
- **บทบาทที่วางไว้ (2026-10-11):** เครื่องควบคุม**เสียงตามสาย**ภายในศูนย์ปฏิบัติธรรมพัทลุง สั่งเปิด/ปิดผ่าน Remote ในวง LAN
- ยังไม่กำหนดจุดตั้งเครื่องและผู้ดูแล

### แนวทางระบบเสียงตามสาย (ร่าง)
- **เส้นเสียง:** ช่อง line-out ด้านหลัง (3.5 mm) → สาย 3.5 mm to RCA → AUX ของแอมป์ ถ้ามีเสียงฮัม ให้ใส่ ground loop isolator ^[inferred]
- **เปิด/ปิดแอมป์:** ใช้ smart plug (เช่น Tapo P110/Sonoff) แล้วเปิดสวิตช์แอมป์ค้างไว้ที่ ON โดยกำลังไฟของแอมป์ต้องไม่เกินพิกัดของปลั๊ก
- **ตั้งเวลา:** ใช้ Task Scheduler + VLC เล่นไฟล์ตามเวลา (ระฆัง/สวดมนต์/ประกาศ)
- **Remote:** ใช้ RustDesk/AnyDesk หรือ Windows RDP (ต้องเป็น Pro) — ถ้าใช้ RDP ต้องตั้ง Remote audio = **"Play on remote computer"** ไม่อย่างนั้นเสียงจะไปออกที่เครื่องที่สั่ง แทนที่จะออกลำโพง
- **ตั้งค่าเครื่องแบบ appliance:** ใน BIOS ตั้ง AC Recovery = Power On + เปิด Wake-on-LAN, ตั้ง auto-login, ปิด sleep, ใช้ IP แบบ fix, ใช้สาย LAN

## แผนอัปเกรด (แนะนำ 2026-10-11, ปรับ 2026-10-16)
**SSD**
- ชนิด: SSD **SATA 2.5"** (เครื่องไม่มีช่อง M.2) ขนาด 256–512 GB
- ชิปเซ็ต H61 รองรับ SATA แค่ 3 Gb/s → ความเร็วสูงสุดราว 250–280 MB/s ใช้ SSD รุ่นประหยัดก็พอ ไม่ต้องซื้อรุ่นแพง ^[inferred]
- รุ่นแนะนำ: Kingston A400, Crucial BX500/MX500, WD Blue SA510
- ต้องมี **ถาดแปลง 2.5" → 3.5"** เพื่อใส่ในถาด HDD สีน้ำเงินเดิม
- เสียบ SSD ที่พอร์ต SATA 0 ให้เป็นไดรฟ์บูต ส่วน HDD 500 GB ใช้เก็บข้อมูลต่อได้

**RAM**
- สเปก: **DDR3 1600 MHz (PC3-12800)** แบบ UDIMM 240 ขา ไม่ใช่ ECC ไฟ 1.5 V (DDR3L 1.35/1.5 V ใช้ได้)
- CPU เป็น Gen 3 (i3-3220) → RAM ทำงานเต็ม 1600 MHz
- ตอนนี้มี **4 GB ×1** → ทางที่คุ้มที่สุดคือ **ซื้อเพิ่ม 4 GB DDR3-1600 อีก 1 แถว = 8 GB dual channel** (ถ้าได้ Kingston KVT8FP-HYC หรือ 2Rx8 สเปกเดียวกันยิ่งดี)
- ถ้าจะขึ้น 16 GB ต้องซื้อ **8 GB ×2** แทนของเดิม และต้องเป็นแบบ low-density (16 ชิป) เท่านั้น เพราะแบบ high-density ที่ราคาถูกใช้กับแพลตฟอร์ม Intel ไม่ได้

**ถ้าใช้เป็นเครื่อง Present ด้วย (ประเมิน 2026-10-16)**
- เครื่องมีช่อง **HDMI** ในตัว (ยืนยันแล้ว) → **ไม่ต้องซื้อการ์ดจอ** ต่อโปรเจกเตอร์/ทีวีได้ทั้งภาพและเสียง และใช้ VGA + HDMI พร้อมกันเป็น 2 จอได้ (presenter view)
- กราฟิก HD 2500 พอสำหรับสไลด์และวิดีโอ 1080p ไม่เหมาะกับวิดีโอ 4K
