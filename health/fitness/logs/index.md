# บันทึกสุขภาพประจำวัน

ข้อมูลจาก Xiaomi Smart Band 9 ผ่าน Mi Fitness  
Template: [[health/fitness/logs/daily-template]]

## วิธีบันทึก

1. เปิด Mi Fitness → ดูข้อมูลแต่ละหน้า: การนอน / ก้าว / แคลอรี่ / SpO2
2. คัดลอก `daily-template.md` → ตั้งชื่อ `YYYY-MM-DD.md`
3. กรอกข้อมูลจากแต่ละหน้าใน Mi Fitness
4. เพิ่ม link ในตารางด้านล่าง

## เป้าหมายรายวัน

| ตัวชี้วัด | เป้าหมาย | หมายเหตุ |
|----------|----------|---------|
| ก้าว | ≤ 10,000 | Hard cap — ห้ามเกิน |
| หลับลึก | ≥ 1h45m | เกณฑ์ตื่น 04:30 สดชื่น |
| HR ขณะนอน | < 65 BPM | |
| SpO2 | ≥ 95% | |
| แคลอรี่ | 700–800 kcal | |
