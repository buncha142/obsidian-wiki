# ผล CT Scan ช่องท้อง — 4 มิถุนายน 2566

**การตรวจ:** CT Whole Abdomen with Contrast Enhancement (MDCT)  
**สถานที่:** ADD:LIFE Center Bangkok  
**รังสีแพทย์:** นพ. บุณยวี หาทัพเพียมสุข  
**วันที่รายงาน:** 4 มิถุนายน 2566  
**เหตุผลที่ตรวจ:** ประวัติโรคกระเพาะอาหาร (History of gastritis)

## ผลการตรวจแต่ละอวัยวะ

| อวัยวะ | ผล |
|--------|-----|
| กระเพาะอาหารและลำไส้ | ✓ ปกติ — ไม่พบก้อนหรือผนังหนาผิดปกติ ไม่มีน้ำในช่องท้อง |
| ตับ | ✓ ปกติ — ขนาด รูปร่าง ความหนาแน่นปกติ ไม่พบก้อน หลอดเลือดตับโปร่ง |
| ถุงน้ำดีและท่อน้ำดี | ✓ ปกติ — ไม่พบนิ่ว ไม่พบการโป่งพอง |
| ม้าม | ✓ ปกติ — ไม่พบก้อน |
| ตับอ่อน | ✓ ปกติ — ขนาดปกติ ไม่พบก้อนหรือท่อโป่งพอง |
| ต่อมหมวกไต | ✓ ปกติ |
| ไตและกระเพาะปัสสาวะ | ✓ ปกติ — ไม่พบนิ่ว ไม่พบก้อน ไม่มีภาวะไตบวม |
| ต่อมลูกหมาก | ✓ ปกติ |
| ต่อมน้ำเหลืองช่องท้อง | ✓ ไม่พบต่อมน้ำเหลืองโต |
| กระดูก | ✓ ไม่พบรอยโรค |
| ปอดส่วนล่าง | ✓ ไม่พบก้อน — มี dependent atelectasis เล็กน้อย (พบได้ปกติ) |

## สรุปผล (IMPRESSION)

> **Unremarkable study — ผลปกติทุกอย่าง**

ไม่พบความผิดปกติใดๆ ในช่องท้องทั้งหมด

## บริบทการตรวจ

การทำ CT ครั้งนี้สั่งตรวจในช่วงเดียวกับที่มีประวัติ[[health/conditions/gastritis|โรคกระเพาะ]] (Erosive Gastritis + H. pylori positive จากการส่องกล้องปี 2565) เพื่อตัดความเป็นไปได้ของก้อนหรือความผิดปกติอื่นในช่องท้อง ผลออกมาปกติ ซึ่งเป็นข้อมูลที่ดี ^[inferred]

## ดูเพิ่มเติม
