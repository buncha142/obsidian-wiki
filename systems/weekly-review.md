# Weekly Review — SOP วางแผนสัปดาห์ + Big 3 ล่วงหน้า

## หลักการ

ปัญหา "ไม่มีเวลาทำ To-Do List ทุกเช้า" ไม่ได้แก้ด้วยการหาเวลาเพิ่ม — ตารางมีช่อง 08:45–09:30 อยู่แล้ว ([[health/daily-routine]]) แต่ถ้าต้องคิดจากศูนย์ทุกเช้าว่า "วันนี้ควรทำอะไร" มันจะช้าและมักโดนงานเร่งด่วนตัดจังหวะ

Weekly Review ทำหน้าที่ **ผลิตวัตถุดิบล่วงหน้า** — ทำครั้งเดียวต่อสัปดาห์ (60 นาที) แทนที่จะคิดใหม่ทุกวัน (7 ครั้ง) — ตามหลัก Task Atomization ใน `CLAUDE.md`: งานใหญ่ต้องถูกย่อยเป็นก้อน 15–30 นาทีก่อนถึงจะลงมือได้

## เวลา

**ศุกร์ 14:00–15:00** (ใช้ชั่วโมงแรกของ Deep Work) — ถ้าศุกร์ติดงานคณะสงฆ์ประจำ ย้ายไปวันอื่นได้ แต่ต้องคงที่ทุกสัปดาห์ (environment design ต้องการความสม่ำเสมอ ไม่ใช่ทำเมื่อมีเวลาว่าง)

## ขั้นตอน (60 นาที)

| นาที | ทำอะไร |
|---|---|
| 1–10 | **ปิดงานที่เสร็จ** — ไล่ `TASKS.md` ทุกหมวด ขีดถูก/ย้าย Done ที่ตกหล่นจาก Daily Shutdown |
| 11–25 | **กวาด deadline จริง** — เปิด `01_Projects/*/_index.md` ทุกโครงการที่ยังไม่ archive ดูตาราง "กำหนดเวลา/สถานะ" ภายใน (มักเร็วกว่า deadline ทางการ) + เช็ค `TIMELINE.md` ถ้ามี — ห้ามดูแค่ `TASKS.md` |
| 26–40 | **ย่อยงานใหญ่** — งานไหนในสัปดาห์หน้าเป็นก้อนใหญ่ (>30 นาที) ให้ย่อยเป็น subtask 15–30 นาทีตามหลัก 5-Level ใน `CLAUDE.md` |
| 41–55 | **วาง Big 3 ล่วงหน้าทั้ง 7 วัน** — สำหรับแต่ละวันจันทร์–อาทิตย์ เลือกไม่เกิน 3 งานหลักที่สำคัญที่สุด เรียงตาม: deadline ใกล้สุดก่อน > งานที่บล็อกงานอื่น > งานที่เหลือ เขียนลง `TASKS.md` หัวข้อ `## 🎯 สัปดาห์นี้` |
| 56–60 | ทบทวนภาพรวม — เช็คว่า Big 3 แต่ละวันไม่ชนกับ Time Blocking fixed ([[health/daily-routine]]) และงานโทร/ประสานงานอยู่ในช่วง Shallow Work (08:15–08:45, 13:00–14:00) ไม่ใช่ Deep Work |

## กฎ Big 3

- วันละไม่เกิน **3 งานหลัก** เท่านั้น — งานอื่นที่เหลือรออยู่ใน `TASKS.md` ตามปกติ แต่ไม่ถูกนับเป็น "งานที่ต้องทำวันนี้"
- แต่ละงานควรถูกย่อยจนทำได้ในบล็อกเดียว (15–30 นาที หรือ 1 บล็อก Deep Work 14:00–17:00 สำหรับงานคิดเข้มข้น)
- ทุกเช้า 08:45–09:30 (หลังประชุมองค์กร) แค่ **หยิบ Big 3 ของวันนั้นมาวาง** จากที่เตรียมไว้ ไม่ต้องคิดใหม่ — ถ้าสถานการณ์เปลี่ยนจริงๆ ค่อยปรับตอนนั้น
