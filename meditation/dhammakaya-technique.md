# เทคนิคสมาธิสายธรรมกาย

## หลักการพื้นฐาน

สมาธิสายธรรมกายใช้ **ศูนย์กลางกาย** (บริเวณกลางท้อง ประมาณ 2 นิ้วเหนือสะดือ) เป็นจุดตั้งของใจ และใช้ **องค์พระ** (ภาพพระพุทธรูปในใจ) เป็นเครื่องยึดเหนี่ยวสติ

## วิธีปฏิบัติ

### ท่านั่ง
- นั่งขัดสมาธิ มือขวาทับมือซ้าย วางบนหน้าตัก
- หลังตรง ผ่อนคลาย ไม่เกร็ง
- ถ้าปวดหลัง/คอ → **พิงผนัง ไม่ก้มคอ** ยังรักษาการปฏิบัติได้ ^[inferred]
- หลับตาเบาๆ

### การตั้งใจ (ที่ศูนย์กลางกาย)
1. นึกภาพองค์พระใสๆ ขนาดพอดี วางอยู่ที่ศูนย์กลางกาย
2. **นึกหลวมๆ เน้นสบาย** — ไม่บังคับภาพให้ชัด ไม่เกร็งใจ
3. ถ้าใจวอกแวก → ค่อยๆ นำกลับมาที่ศูนย์กลางกาย โดยไม่โกรธหรือผิดหวัง
4. หายใจตามธรรมชาติ ไม่บังคับลมหายใจ

### สัญญาณสมาธิที่เริ่มลงลึก

| สัญญาณ | ความหมาย |
|---|---|
| **"โปร่ง โล่ง เบา"** | ใจเริ่มสงบ ออกจาก mental chatter ^[extracted] |
| **นิมิตจร** (ภาพที่ลอยมา) | สมาธิเริ่มลงลึก ภาพมาเองโดยไม่ได้นึก |
| ความเงียบภายใน | ความคิดลดลง ใจอยู่กับปัจจุบัน |

> นิมิตจรเกิดขึ้น 2 ครั้งในวันที่ 4 ของการปฏิบัติธรรม — ถือเป็นสัญญาณที่ดี ไม่ใช่สิ่งที่ต้องไปไล่ตาม ^[extracted]

## เทคนิคปรับสำหรับสถานการณ์ต่างๆ

### เมื่อตื่นกลางดึก
- **ห้ามหยิบมือถือ**
- ภาวนาที่ศูนย์กลางกาย ตามลมหายใจเบาๆ
- หากนอนไม่หลับ: ลุกนั่งสมาธิเบาๆ หรือสวดมนต์ในใจ

### เมื่อมีอาการบาดเจ็บ
- คอตกหมอน / ปวดหลัง → พิงผนัง งดก้มคอ
- ยังนั่งได้ 20–30 นาที แทนที่จะงดทั้งวัน
- การปรับตัวคือส่วนหนึ่งของการปฏิบัติ ^[inferred]

### เมื่อตารางเลื่อน
- ไม่ต้องรอตารางที่ "สมบูรณ์" — นั่งได้เมื่อมีเวลา แม้จะสั้น
- 15–20 นาทียังมีค่ากว่าไม่นั่งเลย ^[inferred]

## ความเชื่อมโยงกับสุขภาพ

ข้อมูลจาก [[journal/2025-05-retreat-dhammakaya]] พบว่า:

```
Deep sleep ≥ 1h45m → ตื่น 04:30 สดชื่น → นั่งสมาธิได้เต็มรอบ 60+ นาที
เดิน > 12K ก้าว → ปวดสะสม → นอนหลับๆ ตื่นๆ → พลาดสมาธิวันถัดไป
```

การดูแลร่างกาย (นอนให้พอ, ก้าวไม่เกิน 10K) คือเงื่อนไขสำคัญของการปฏิบัติที่สม่ำเสมอ
